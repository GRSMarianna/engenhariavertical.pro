Política de Privacidade

Última atualização: 03 de maio de 2025  ·  engenhariavertical.pro

1. Quem somos

A Engenharia Vertical é uma empresa especializada em projetos estruturais para residências e pequenos edifícios, atuando no noroeste paulista (São José do Rio Preto, Araçatuba, Olímpia) e na região de Três Lagoas (MS). Nosso site é engenhariavertical.pro.

Este documento descreve como tratamos os dados coletados por meio das nossas ferramentas digitais, incluindo o aplicativo de gestão de anúncios que utilizamos para gerenciar nossas campanhas no Facebook e Instagram via API de Marketing do Meta.

2. Quais dados coletamos

Para o funcionamento da integração com a API de Marketing do Meta, coletamos e processamos:

  • Tokens de acesso à API de Marketing do Meta (armazenados com criptografia).
  • Identificadores de contas de anúncios, Páginas do Facebook e contas do Instagram vinculadas.
  • Dados de desempenho de campanhas: impressões, cliques, alcance, gastos e métricas relacionadas.
  • Configurações de conjuntos de anúncios e segmentações criadas via API.
  • Endereço de e-mail de contato utilizado no cadastro.
Não coletamos senhas, dados bancários ou informações pessoais de pessoas que interagem com os anúncios veiculados.

3. Como utilizamos os dados

Os dados coletados são utilizados exclusivamente para:

  • Autenticar e manter a conexão ativa com a API de Marketing do Meta.
  • Exibir relatórios e métricas das campanhas publicitárias da Engenharia Vertical.
  • Gerenciar e otimizar anúncios no Facebook e Instagram.
  • Enviar alertas e notificações sobre o desempenho das campanhas.

Não utilizamos seus dados para fins publicitários externos, não os vendemos e não os compartilhamos com terceiros sem sua autorização expressa.

4. Permissões da API do Meta utilizadas

O aplicativo solicita apenas as permissões estritamente necessárias para seu funcionamento:

ads_management ads_read business_management pages_read_engagement pages_show_list read_insights instagram_basic instagram_manage_insights
  • ads_management — Criação e gerenciamento de campanhas e anúncios.
  • ads_read — Leitura de dados de campanhas e relatórios de performance.
  • business_management — Acesso ao portfólio de negócios vinculado.
  • pages_read_engagement — Leitura de dados de engajamento das Páginas do Facebook.
  • pages_show_list — Listagem de Páginas associadas à conta.
  • read_insights — Acesso a métricas e insights de desempenho.
  • instagram_basic — Acesso básico à conta do Instagram vinculada.
  • instagram_manage_insights — Leitura de métricas e insights do Instagram.

5. Armazenamento e segurança

Todos os tokens de acesso e dados sensíveis são armazenados com criptografia. Adotamos boas práticas de segurança para proteger as informações contra acesso não autorizado, alteração ou divulgação indevida.

Os tokens de acesso não são mantidos além do estritamente necessário para as operações solicitadas pelo usuário.

6. Retenção e exclusão de dados

Os dados são retidos enquanto a conta estiver ativa no aplicativo. Após a revogação do acesso no painel do Meta ou mediante solicitação expressa, todos os dados associados serão removidos em até 30 dias.

7. Seus direitos

Em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), você tem o direito de:

  • Acessar, corrigir ou solicitar a exclusão dos seus dados pessoais.
  • Revogar o acesso do aplicativo a qualquer momento pelo painel de configurações do Meta.
  • Solicitar a portabilidade dos seus dados.
  • Ser informado em caso de incidente de segurança que possa afetá-lo.

8. Compartilhamento com terceiros

Não vendemos nem compartilhamos seus dados com terceiros para fins comerciais. O único terceiro envolvido no processamento é o Meta Platforms, Inc., necessariamente para viabilizar a integração via API — o que ocorre conforme os Termos de Privacidade do Meta.

9. Alterações nesta política

Esta política pode ser revisada periodicamente. Comunicaremos mudanças relevantes por e-mail ou dentro do aplicativo. O uso continuado após as alterações indica aceitação da versão atualizada.
